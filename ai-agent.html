岗位职责

这个岗位具体做什么

从架构设计到 CI 门禁的完整工程闭环，每一步都有可验证的证据。

  • 编排层设计：用 LangGraph StateGraph 构建 Router→Planner→Skill→Tool→Reviewer 五阶段链路，Pydantic 结构化输出衔接各阶段，支持多步工具调用循环。
  • RAG 与检索工程：语义边界智能切分（chunk 500 / overlap 50）→ Dense+BM25 混合检索 → RRF 融合 → Cross-Encoder 重排 → 生成附引用来源；真实评测检索准确率 93.3% @3。
  • 工具层与接入：Pydantic 严格 Schema 定义工具输入输出，UnifiedMessage 统一多平台消息模型，MCP 协议标准化工具发现。
  • 记忆与容错：双视野记忆（Redis 短期 + PostgreSQL 事实三元组）；错误分类重试 / 降级 / 熔断 / 调用次数限制，防死循环。
  • 评测与可观测性：评测集纳入 CI 每次 push 自动回归；OpenTelemetry + Jaeger 全链路 trace，一次会话 8 个 span 贯穿。
  • 部署与工程化：Docker Compose 本地一键起、K8s Helm（HPA CPU 70%）、pytest + GitHub Actions CI 门禁、敏感信息扫描。
